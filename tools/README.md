# Von Beauty · ferramentas de arte

- Paleta: preto #0E0D0E · grafite #2B2A2C/#3D3D3D · rosé #E9848D · rosé antigo #B26A72 · rosé claro #E6B5BE · off-white #F5F0EE · blush #EBD3D6
- Fontes: Cormorant Garamond (títulos, itálico rosé) + Jost (labels em caixa alta espaçada). Instalar: `npm i @fontsource/cormorant-garamond @fontsource/jost` dentro de `tools/`.
- Logo: `brand/logo_white.png` (fundos escuros/foto) e `brand/logo_dark.png` (fundos claros).
- Imagens: `brand/renders/` (projeto arquitetônico; usar só como ambientação, nunca como endereço atual).
- Feed: 1080x1350 (`build3.py`). Stories 1080x1920 e Reels 9:16 com texto animado (`build_sr.py`).
- Regra visual: alternar claro (off-white/blush) e escuro (preto/grafite/foto) para o feed ficar harmonioso; nunca todo escuro.
- Publicação: JPEG em `https://raw.githubusercontent.com/danielabugermini-bit/vonbeauty-midia/posts/<caminho>` via Windsor.ai (Instagram 17841456987337628).
